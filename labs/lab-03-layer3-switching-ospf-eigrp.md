# Lab 03 - Layer 3 Switching, OSPF, and EIGRP

## Objectives

- Configure Layer 3 switching.
- Configure OSPF.
- Review EIGRP operation.
- Verify routing decisions.

## Steps

1. Enable IP routing on a Layer 3 switch if supported.
2. Configure SVIs for campus VLAN gateways.
3. Configure routed uplinks to core devices.
4. Verify inter-VLAN routing.
5. Configure OSPF area 0.
6. Set router IDs.
7. Configure passive interfaces where appropriate.
8. Verify OSPF neighbors.
9. Verify OSPF routes.
10. Review DR/BDR behavior on broadcast networks.
11. Configure EIGRP if supported by your lab image.
12. Review EIGRP neighbor and feasible successor concepts.
13. Compare routing protocol verification outputs.

## Validation

- SVIs route between VLANs.
- OSPF neighbors form.
- Routing table contains expected routes.
- OSPF and EIGRP differences are documented.

## Review Questions

1. When would you use a routed port instead of an SVI?
2. What causes OSPF neighbor adjacency failures?
3. What is a passive interface?
4. What is an EIGRP feasible successor?
