# Lab 05 - Enterprise Security, ACLs, AAA, and Device Hardening

## Objectives

- Harden device management.
- Configure ACLs.
- Explain AAA.
- Review Layer 2 security controls.

## Steps

1. Review current management access.
2. Require SSH for VTY access.
3. Configure local usernames and strong secrets.
4. Configure exec timeout and login banner.
5. Create a management ACL for VTY access.
6. Configure a standard ACL for a source-based policy.
7. Configure an extended ACL for service filtering.
8. Verify ACL hit counts.
9. Explain authentication, authorization, and accounting.
10. Compare TACACS+ and RADIUS.
11. Configure port security on access ports.
12. Review DHCP snooping and Dynamic ARP Inspection.
13. Save a security baseline.

## Validation

- Management access is restricted.
- ACL behavior matches the intended policy.
- AAA concepts are documented.
- Layer 2 security controls are explained.

## Review Questions

1. Why should management access be restricted?
2. How do standard and extended ACLs differ?
3. Why do enterprises use AAA servers?
4. What does DHCP snooping protect against?
