# Lab 08 - Automation, Controller-Based Networking, APIs, and Exam Review

## Objectives

- Explain controller-based networking.
- Understand APIs and JSON.
- Review automation tools.
- Build an ENCOR study plan.

## Steps

1. Compare traditional CLI operations with controller-based networking.
2. Identify control plane, data plane, and management plane.
3. Explain northbound and southbound APIs.
4. Review Cisco DNA Center or controller concepts.
5. Read a sample JSON object.
6. Identify keys, values, arrays, and nested objects.
7. Explain REST API methods: GET, POST, PUT/PATCH, DELETE.
8. Review Ansible inventory and playbook concepts.
9. Explain idempotency.
10. Map each course lab to ENCOR exam domains.
11. Create a weak-topic list.
12. Write a 14-day study plan.
13. Archive final configurations and notes.

## Validation

- SDN concepts are explained clearly.
- JSON worksheet is correct.
- Automation tool notes are complete.
- Study plan is specific and time-bound.

## Review Questions

1. Why do controllers matter in enterprise networks?
2. What is JSON used for?
3. What does idempotency mean?
4. Which ENCOR domain needs the most review?
