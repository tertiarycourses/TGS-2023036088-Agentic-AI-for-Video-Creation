# Lab 07 - Network Assurance, Telemetry, and Troubleshooting

## Objectives

- Configure basic logging.
- Review telemetry and monitoring concepts.
- Practise structured troubleshooting.
- Produce an operations report.

## Steps

1. Configure logging buffer or syslog destination.
2. Configure NTP or document the time source.
3. Review SNMP manager and agent concepts.
4. Review NetFlow or IPFIX concepts.
5. Configure SPAN or packet capture if supported.
6. Configure IP SLA tracking if supported.
7. Create a controlled fault.
8. Write the symptom and expected behavior.
9. Check interface, VLAN, route, and ACL evidence.
10. Use logs and verification commands to isolate the cause.
11. Fix one issue at a time.
12. Verify end-to-end reachability.
13. Write a troubleshooting report.

## Validation

- Logs or assurance notes are captured.
- Troubleshooting flow is logical.
- Fix is verified.
- Report includes evidence, cause, fix, and prevention.

## Review Questions

1. Why must device clocks be synchronized?
2. What is the purpose of NetFlow?
3. How does SPAN help troubleshooting?
4. Why should engineers change one thing at a time?
